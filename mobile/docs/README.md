# Mobile Documentation Index

- `PRODUCT_OVERVIEW.md` — product scope, roles, user journeys, source of truth.
- `DESIGN_SYSTEM.md` — exact web brand tokens and mobile equivalents.
- `ARCHITECTURE.md` — folders, data flow, env config, demo mode.
- `NAVIGATION.md` — navigators, role-based tabs, routes.
- `API_INTEGRATION.md` — verified endpoints, contracts, and backend gaps.
- `DATABASE_MAPPING.md` — Laravel tables/models that back each mobile feature.
- `FEATURES.md` — feature mapping: web feature, mobile screen, endpoint, role, status.
- `AUTHENTICATION.md` — verified backend auth and current mobile limitation.
- `PERFORMANCE.md` — loading and rendering rules.
- `COMPONENTS.md` — reusable component catalogue.
- `DEVELOPMENT_GUIDELINES.md` — conventions and verification commands.
- `IMPLEMENTATION_STATUS.md` — what is actually implemented.

Backend docs live at the repository root under `docs/`. They are authoritative for
business rules; this directory describes the mobile client only.
